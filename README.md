# SVTECH Company Website

A modern and responsive company website built using **React.js**.

## 🚀 Features

- Responsive Design
- Modern User Interface
- Fast Performance
- Mobile Friendly
- Easy to Maintain

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- GitHub Actions
- AWS S3
- AWS CloudFront

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/satyamedicharla-28/SVTECH-COMPANY-WEBSITE.git
```

Go to the project folder:

```bash
cd SVTECH-COMPANY-WEBSITE/svtech-react
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

## 🚀 Deployment

The website is automatically deployed to AWS using GitHub Actions.
